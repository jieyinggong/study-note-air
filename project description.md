
To clarify upfront: Thryvv already has a functional MVP in place.
For this project, we are not looking to rebuild the core product, but rather to prototype a specific, high-value layer that supports our B2B2C model.
Project Context (Brief)
Thryvv is a B2B2C wellness platform where:
• Organisations (employers, insurers, banks, institutions) are the paying customers
• Individuals are the end users engaging with mental fitness content, prompts, programmes, and events

The platform must balance:

• a personal, human-centred experience for individuals
• an anonymised insight and reporting layer for organisations

Clear Project Ask

  We would like the team to design and prototype an organisational insight layer (sentiment report) that sits on top of existing user engagement data.

Scope of Work (What the team should focus on)

Using mocked or sample data where needed, the team will:

1. Define a data model for anonymised wellness engagement
• engagement frequency
• prompt or programme completion
• dominant themes (e.g. stress, motivation, overwhelm)
• return behaviour over time

2. Prototype a simple internal dashboard (admin / organisational view) that visualises:
• engagement trends over time
• which content or prompt formats perform best
• high-level cohort patterns (no individual data)

3. Demonstrate how this insight layer could support B2B decision-making, for example:
• understanding when engagement spikes or drops
• identifying which interventions resonate most
• surfacing patterns without surveillance or individual tracking

  

Deliverables
• A lightweight web prototype or dashboard (non-production)
• Clear documentation outlining:
• assumptions made
• data structures used
• privacy and anonymisation considerations
• technical limitations and future scalability ideas

  

Important Constraints
• No individual-level reporting
• No clinical diagnosis or monitoring
• POPI-first, anonymised and aggregated insights only (AI generated sentiment report)
